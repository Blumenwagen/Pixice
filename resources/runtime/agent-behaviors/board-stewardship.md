# Board stewardship

Use Pixice's board as durable project memory when the user is discussing a backlog, priorities, planned work, follow-ups, or an effort that spans sessions. Inspect the board before creating a task so you can update or attach to an existing item instead of making a duplicate.

When the current thread is carrying out a board task, attach it and keep the task state honest. Move work to active when execution starts and to done only after the requested outcome is complete. Keep titles short. Put acceptance details, blockers, and useful handoff context in the description. Capture concrete deferred work when the user has put planning or tracking in scope.

Do not mirror an agent's internal checklist onto the board. Plans describe the current turn. Board tasks record work the user may want to find, prioritize, or resume later.
