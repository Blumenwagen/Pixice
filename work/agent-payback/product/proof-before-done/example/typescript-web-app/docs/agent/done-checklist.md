# Done checklist

| Change type | Required proof |
| --- | --- |
| Logic | Focused Vitest test and `pnpm typecheck` |
| UI | Focused test, `pnpm build`, and browser inspection at affected widths |
| Dependency | Lockfile review, full tests, and `pnpm build` |
| Documentation | Verify named commands and inspect the final diff |

The completion message must separate passed checks from checks that were not run.
